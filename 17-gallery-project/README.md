# 📸 Pixora

Pixora is a modern and responsive React image gallery that fetches stunning photos from the **Lorem Picsum API**. It allows users to browse high-quality images page by page with a clean and responsive interface built using **React**, **Axios**, and **Tailwind CSS**.

## ⚙️ Installation

Clone the repository:

```bash
git clone <repository-url>
```

Move into the project folder:

```bash
cd Pixora
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

---

## 📡 API

Pixora uses the **Lorem Picsum API**:

```text
https://picsum.photos/v2/list?page=1&limit=20
```

---

## 📖 How It Works

1. The app fetches images using Axios.
2. Images are displayed in responsive cards.
3. Each card displays:

   * Image
   * Author name
4. Clicking an image opens its original page.
5. Users can switch between pages using Previous and Next buttons.
